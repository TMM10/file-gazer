# File Gazer development

- The Git ignore file permits only an explicit source-file allowlist. Add new intended source files deliberately; do not broadly allow generated directories.
- Keep personal settings, scan exports, captures, diagnostic reports, generated fixtures and compiled binaries out of Git.
- Use virtual browser inventories or a dedicated fixture-only native service for verification. Do not replace a user's live scan or perform file actions on personal files while testing.
- Preserve byte-proportional sibling areas, exact remainder totals, zero-byte list entries, parent enclosure and spacing between moving bubbles.
- Keep camera transforms and gesture animation independent from API requests. Preserve revision-aware caches and read-only scan behavior.
- Build with `backend/build.ps1`. Use `tools/package_release.py` for the explicit runtime-only portable package.
- Preserve the vendored library license. Do not assign an application license without the repository owner's decision.
